# RQ2 analysis notes

## Coding protocol (summary)

1. **Sample.** 690 rejected suggested edits, random sample sized for 99% confidence level and 5% margin of error. Exclude conflict-based rejections.
2. **Open coding.** First ~100 edits used to draft categories, merge near-duplicates, and write decision rules.
3. **Independent coding.** Two authors label all 690 edits with a single primary reason, using the pre/post diff (and post context when needed).
4. **Agreement.** Cohen’s κ = 0.80; disagreements resolved by discussion, with a third author adjudicating unresolved cases.
